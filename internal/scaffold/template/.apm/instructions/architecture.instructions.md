# Architecture Instructions

Use the `golang-clean-arch` skill for all architecture-related work. Read and
apply it before:

- creating, extending, or restructuring a feature or workflow;
- deciding which domain, use-case, port, adapter, configuration, or dependency
  registration components are needed;
- deciding package ownership, placement, dependency direction, or
  cross-feature collaboration; and
- reviewing changes for architectural compliance.

Create only the components required by real behavior, and follow the skill's
implementation workflow and architecture validation checklist.
